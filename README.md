# fs0ciety - OSINT Recon Tool 🕵️‍♂️

A basic Open Source Intelligence (OSINT) tool written in Python for educational purposes. It allows users to perform basic reconnaissance on public domains and IP addresses.

## 🚀 Features
- **DNS Resolution**: Find the IP address behind a domain name.
- **IP Geolocation**: Get public information (Country, City, ISP) about an IP address.
- **SSL Audit**: Check the SSL/TLS certificate of a website.

## ⚠️ Legal Disclaimer (Educational Purpose Only)
**This tool is strictly for educational and ethical purposes.** 
It only queries public APIs and databases. It does NOT scan, attack, or access private systems. Never use OSINT tools to stalk or target individuals without explicit consent.
